# P20 本地 SQLite WAL 与审计备份

新增命令：

```powershell
py scripts\create_local_backup.py --profile simulation --audit-days 14
py scripts\create_local_backup.py --profile production_readonly --audit-days 14
```

备份写入项目 F 盘目录 `runtime_data/backups/<profile>/<UTC时间戳>/`。每次创建独立目录，拒绝覆盖已有目录；本工具不包含删除或恢复操作。

内容包括：SQLite 在线一致性备份、profile 配置、策略登记、项目状态和最近 14 天 JSONL 审计。`manifest.json` 记录 SHA-256、文件相对路径及 `PRAGMA integrity_check` 结果。
