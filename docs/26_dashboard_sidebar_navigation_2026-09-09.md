# Dashboard 侧边栏导航修复（2026-09-09）

## 已修复

侧边栏六个导航项现在可点击，并支持键盘 `Enter` / `Space`：

- 运行总览：回到顶部运行指标；
- 策略袖套：定位策略资金、NAV、收益率；
- 账户与持仓：定位 QMT 只读持仓；
- 委托与成交：定位委托/成交只读安全状态；
- 行情健康度：定位 Redis/QMT/行情新鲜度状态；
- 审计与日志：定位最近验证与安全状态。

导航只改变页面定位和选中状态，不调用 QMT、Redis、下单或撤单接口。

## 验证

Playwright 逐项点击 6 个导航项均成功切换选中状态；键盘 Enter 操作成功；浏览器控制台错误为 0。
