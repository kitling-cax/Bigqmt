将 `<CANDIDATE>` 替换为本机对应的共享路径：

```powershell
$candidate = '<CANDIDATE>'
Select-String -LiteralPath (Join-Path $candidate 'version.py') -Pattern '^__version__\s*=\s*"0\.3\.56"'
foreach ($f in @('execution_admission.py','adapter_factory.py','redis_rpc.py','adapters\order_guarded.py')) {
  if (-not (Test-Path (Join-Path $candidate $f))) { throw "missing protected file: $f" }
```

## 6. 只读验收

升级完成后，用户或本机操作员再在两个 QMT 中启动 `BIGQMT_BRIDGE`，然后执行：

```powershell

py -3.12 .\scripts\check_bridge_ping.py --profile production_readonly --timeout 8
```

两条都应满足：


这是只读 Ping，不下单。正式账户如果显示 `allow_order_methods=false`，表示运行期开关仍锁定，不代表桥接包没有更新。
