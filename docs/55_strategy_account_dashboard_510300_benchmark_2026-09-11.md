# 策略账户 Dashboard 与沪深 300 ETF 基准

## 本次交付

模拟盘 Dashboard 的 `/simulation/strategies` 路由现为白底的“策略账户”页面。每个已注册策略均作为独立资金袖套展示，券商总账户只用于事实对账，不会把既有外部持仓计入任何策略收益。

页面展示：

- 初始资金、当前净值、累计收益、当日盈亏、最大回撤；
- 策略归属持仓、可用现金、冻结资金、持仓市值、已实现盈亏；
- 策略净值曲线，以及同一起点复基的沪深 300 ETF（`510300.SH`）虚线基准；
- 策略相对 `510300` 的超额收益。

## 数据口径

`strategy_benchmark_snapshots` 是 SQLite WAL 中独立的基准快照表。首次取得的 `510300.SH` 收盘价被设为基准净值 100；之后基准净值按价格比例复基。它仅用于比较，不表示策略实际持有 `510300`。

首次收盘基准点已随 `daily_20260911_close` 写入：`510300.SH = 4.579`，策略 A 的相对基准收益在首日为 `-1.6511%`。每日 16:20 的只读运行记录会继续补充收盘净值和基准点；无行情时明确标记 `UNAVAILABLE`，不伪造价格。

- 页面/API 没有下单、撤单或放开订单权限的入口；
